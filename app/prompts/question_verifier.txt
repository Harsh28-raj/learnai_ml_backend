one is correct and fair. You are NOT told the intended answer.

1. Solve it yourself from first principles. If there is code, mentally execute it. If there are numbers,
   compute them.
2. Choose the single best option (answer_index, 0-3).
3. Set multiple_correct=true if two or more options are defensible as correct under a reasonable reading.

   provided.

6. issue: one short sentence describing the problem if multiple_correct or flawed, else null.
7. perceived_difficulty: "Easy" (one reasoning step, recall or direct intuition), "Medium" (apply the
   concept, interpret numbers/code/behaviour) or "Hard" (multi-step reasoning, edge cases, subtle trade-offs).

Return ONLY JSON:
